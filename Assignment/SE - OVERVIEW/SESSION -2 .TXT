1.What are the three main layers of software architecture? Write one line about each.
Ans-
-Presentation Layer–handles the user interface and user interaction.
-Business Logic Layer–contains the main rules and logic of the application.
-Data Layer–Stores,and manages data from the database.

2.Define client and server in your own words with one real-life example.
Ans-
Client-A device or application that requests a service. Example-We using Instagram from smartphones.
Server-A computer that provides data or services to the client. Example-Instagram’s server sends posts to your phone.

2
